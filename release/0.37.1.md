ModAVD 0.37.1，构建号 `mas-37`，基于 Google AOSP Android Emulator 37.2.10 构建。安装、升级和反馈见仓库 README 与 `docs/`。

## 更新内容

### 变更

- 包里的管理器 ModAVD.exe 和命令行 tools\modavd.exe 从 0.3.0 升到 0.3.1；模拟器还是 mas-37，没有重编。各项改动见 [ModAVDManager 的 Release](https://github.com/ModAVD/ModAVDManager/releases)。
- 开发、测试用的根目录可以在 mas-avd.json 里写 portBase，换一段实例端口，不再和同一台电脑上别的根目录抢端口。AUTO-MAS 不认这个设置，设了的根目录不要加进 AUTO-MAS。（[#75](https://github.com/ModAVD/ModAVD/issues/75)）

### 修复

- 用管理器或命令行开机的实例不再用 netsim，也就不再连整机共用的 netsimd；以前它一卡住，之后开的模拟器都开不了机。（[#82](https://github.com/ModAVD/ModAVD/issues/82)）
- 用管理器或命令行关机时，先让前台应用退到后台存数据、把数据写回磁盘，再走安卓的正常关机。以前等安卓关机超时以后只能直接结束进程，等于断电，游戏最后写的文件可能丢失。（[#88](https://github.com/ModAVD/ModAVD/issues/88)）
- 只在 Windows「Internet 选项」里设了代理的电脑上，用 modavd update 从 GitHub 更新连不上；现在和补全组件一样读这个代理。（[#78](https://github.com/ModAVD/ModAVD/issues/78)）
- 打开管理器时，不会再另外弹出一个完整的 Edge 浏览器窗口：管理器用的 Edge 不再自动登录 Microsoft 账户，也不同步、不加载扩展；关掉管理器窗口时，也不会再在后台启动你自己的 Edge。（[#90](https://github.com/ModAVD/ModAVD/issues/90)）

### 说明

- 升级后打开管理器，窗口出来以后会在后台删掉管理器旧的浏览器配置目录 %LOCALAPPDATA%\ModAVD\ui-edge；同一台电脑上还开着旧版管理器时先跳过，下次打开再删。里面是以前同步进去的收藏夹、历史记录和密码的副本，你自己的 Edge 和 Microsoft 账户里的数据不受影响。（[#90](https://github.com/ModAVD/ModAVD/issues/90)）

## 怎么更新

- 这一版只换了管理器和命令行（0.3.0 → 0.3.1），模拟器、执行桥、宿主输入法都和 0.37.0 一样。用 Mirror 酱（填了 CDK）更新时只下变了的文件；从 GitHub 下的还是整包。
- 先关掉所有实例（在 AUTO-MAS 或管理器里关机）再更新；关掉后稍等半分钟，模拟器的附属进程退出要十几秒，覆盖时提示文件被占用就再等一会儿重试。手动更新时用新包整个覆盖解压，`avd` 文件夹不会被动到。不用重新下载组件，也不用在 AUTO-MAS 里重新添加。
- 第一次装：主包里没有外层文件夹，请用右键「全部解压缩」或 7-Zip「解压到 <包名>\」。解压后双击「补全组件.bat」下载 adb 和系统镜像，再双击 `ModAVD.exe` 新建实例；要接入 AUTO-MAS 的，再到 AUTO-MAS 里添加，详见 `说明.txt`。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 0.37.0 相同。这一版对 AUTO-MAS 没有新要求。

## 已知问题

- 删除游戏或文件后虚拟磁盘不缩小；后续写入会复用空间。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- FAT32 / exFAT 上的首次建盘空间检查尚未实测，建议使用 NTFS。（[#3](https://github.com/ModAVD/ModAVD/issues/3)）
- 《阴阳师》冷启动偶尔停在「正在获取音频列表...」，关掉重开即可。（[#36](https://github.com/ModAVD/ModAVD/issues/36)）
- AUTO-MAS 自己起的模拟器（不经过管理器或命令行），多开时 netsimd 还可能卡住，之后所有实例都开不了机；在任务管理器里结束 netsimd 进程再开机就好。用管理器或命令行开机的实例已经不用 netsimd 了。（[#65](https://github.com/ModAVD/ModAVD/issues/65)）
- Windows 注销、重启或关机时，开着的实例还是直接断电，不会先让安卓关机，和以前一样。关电脑前请先在 AUTO-MAS 或管理器里关掉实例。（[#60](https://github.com/ModAVD/ModAVD/issues/60)）

## English

ModAVD 0.37.1, build `mas-37`, built on Google AOSP Android Emulator 37.2.10. Installation, upgrades and feedback: see https://modavd.github.io/.

### Changes

- The manager ModAVD.exe and the command line tools\modavd.exe in the package go from 0.3.0 to 0.3.1. The emulator is still mas-37 and was not rebuilt. See the [ModAVDManager releases](https://github.com/ModAVD/ModAVDManager/releases) for each change.
- A root folder used for development or testing can set `portBase` in `mas-avd.json` to move its instances to a range of ports of their own, so they no longer collide with the same-numbered instances of another root folder on the same computer. AUTO-MAS does not read this setting, so do not add such a root folder to AUTO-MAS. ([#75](https://github.com/ModAVD/ModAVD/issues/75))

### Fixes

- Instances started from the manager or the command line no longer use netsim, so they no longer connect to the netsimd that every emulator on the computer shares. Before, once it hung, no emulator started afterwards could boot. ([#82](https://github.com/ModAVD/ModAVD/issues/82))
- Shutting down from the manager or the command line first sends the foreground app to the background so it can save, writes the data back to disk, and then goes through Android's normal shutdown. Before, if Android took too long to shut down, the emulator could only be ended outright, which is the same as pulling the plug, and files a game wrote last could be lost. ([#88](https://github.com/ModAVD/ModAVD/issues/88))
- On computers whose proxy is set only in Windows' Internet Options, `modavd update` could not reach GitHub; it now reads that proxy, as component download already did. ([#78](https://github.com/ModAVD/ModAVD/issues/78))
- Opening the manager no longer pops up a full Edge browser window: the Edge the manager uses no longer signs in to the Microsoft account automatically, syncs, or loads extensions, and closing the manager window no longer starts your own Edge in the background. ([#90](https://github.com/ModAVD/ModAVD/issues/90))

### Notes

- After the update, the manager deletes its old browser profile folder `%LOCALAPPDATA%\ModAVD\ui-edge` in the background once its window is open; if an older manager is still open on the same computer, it waits until the next time. The folder holds copies of favorites, history and passwords that were synced into it; your own Edge and the data in your Microsoft account are not affected. ([#90](https://github.com/ModAVD/ModAVD/issues/90))

### How to update

- This version only replaces the manager and the command line (0.3.0 to 0.3.1); the emulator, the execution bridge and the host input method are the same as in 0.37.0. Updating through MirrorChyan (with a CDK) downloads only the changed files; downloading from GitHub still means the whole package.
- Shut down all instances first (in AUTO-MAS or in the manager), then wait about half a minute: the emulator's helper processes take a dozen seconds or so to exit. If extracting reports a file in use, wait a little and try again. To update by hand, extract the whole new package over the old one; the `avd` folder is left alone. There is no need to download the components again or to add ModAVD to AUTO-MAS again.
- First install: the main package has no top-level folder, so use "Extract All…" or 7-Zip "Extract to <package name>\". Then double-click 补全组件.bat to download adb and the system image, and double-click `ModAVD.exe` to create an instance. To use it with AUTO-MAS, add it there as well; see 说明.txt.

### AUTO-MAS version

- `v5.7.0` or later is recommended, as for 0.37.0. This version has no new requirements for AUTO-MAS.

### Known issues

- The virtual disk does not shrink after games or files are deleted; later writes reuse the space. ([#2](https://github.com/ModAVD/ModAVD/issues/2))
- The free-space check for creating the first disk on FAT32 / exFAT has not been tested; NTFS is recommended. ([#3](https://github.com/ModAVD/ModAVD/issues/3))
- Onmyoji occasionally stops at "正在获取音频列表..." (fetching the audio list) during a cold start; close it and start it again. ([#36](https://github.com/ModAVD/ModAVD/issues/36))
- Emulators that AUTO-MAS starts itself (not through the manager or the command line) can still hit a hung netsimd with several instances, after which no instance can start; end the netsimd process in Task Manager and start again. Instances started from the manager or the command line no longer use netsimd. ([#65](https://github.com/ModAVD/ModAVD/issues/65))
- When Windows logs off, restarts or shuts down, running instances are still cut off without letting Android shut down first, as before. Shut the instances down in AUTO-MAS or the manager before turning off the computer. ([#60](https://github.com/ModAVD/ModAVD/issues/60))
