ModAVD 0.38.2，构建号 `mas-38`，基于 Google AOSP Android Emulator 37.2.10 构建。安装、升级和反馈见仓库 README 与 `docs/`。

## 更新内容

### 新增

- 可选的 Google Play 商店：补全组件时勾上 Play 商店服务（或导入自己的文件），再在实例的「更多操作」里补全；新建的实例默认不带。（[#125](https://github.com/ModAVD/ModAVD/issues/125)）

### 变更

- 包里的管理器和命令行升到 0.5.0，详见 [ModAVDManager 的 Release](https://github.com/ModAVD/ModAVDManager/releases)；模拟器还是 mas-38，没有重编。
- 补全组件、收集问题信息改在管理器里做，包根的三个 .bat 不再随包。（[#45](https://github.com/ModAVD/ModAVD/issues/45)）

## 怎么更新

- 这一版只重新打包：模拟器还是 mas-38，没有重编；包里的管理器和命令行升到 0.5.0；执行桥、宿主输入法都和 0.38.1 一样。
- 包根的「补全组件.bat」「收集问题信息.bat」「复制配置信息.bat」和 `tools` 下对应的三个脚本不再随包：在管理器里补全组件、收集问题信息，也可以运行 `tools\modavd.exe components fetch`、`tools\modavd.exe collect-info`。（[#45](https://github.com/ModAVD/ModAVD/issues/45)）
  - 用 `modavd update` 自动换包会删掉这六个旧文件；手动覆盖解压会留下它们，可以自己删掉。
- 要 Play 商店的：在管理器的「补全组件」里勾上「同时补全 Google Play 商店服务」（约 1.5 GB），或点「使用我自己的文件…」导入 Google 官方的镜像压缩包；然后在实例的「更多操作」里点「补全 Google Play 商店…」。登录时提示「设备未经 Play 保护机制认证」的，用同一处的「复制 GSF ID」去 Google 登记。查 Play Integrity 的游戏多半还是过不了。不要商店的什么都不用做。（[#125](https://github.com/ModAVD/ModAVD/issues/125)）
- 先关掉所有实例（在 AUTO-MAS 或管理器里关机）再更新；关掉后稍等半分钟再覆盖。手动更新时用新包整个覆盖解压，`avd` 文件夹不会被动到。不用在 AUTO-MAS 里重新添加。
- 第一次装：主包里没有外层文件夹，请用右键「全部解压缩」或 7-Zip「解压到 <包名>\」。解压后双击 `ModAVD.exe`，点上方提示里的「补全组件」下载 adb 和系统镜像，再新建实例；要接入 AUTO-MAS 的，再到 AUTO-MAS 里添加，详见 `说明.txt`。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 0.38.1 相同。这一版对 AUTO-MAS 没有新要求。

## 已知问题

- 删除游戏或文件后虚拟磁盘不会自动缩小，模拟器的 trim 还不会真正回收空间；要省空间，请在关机后用管理器的「整理磁盘」或命令行 `modavd disk <编号> compact`。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- 《阴阳师》冷启动偶尔停在「正在获取音频列表...」，关掉重开即可。（[#36](https://github.com/ModAVD/ModAVD/issues/36)）
- AUTO-MAS 自己起的模拟器（不经过管理器或命令行），多开时 netsimd 还可能卡住，之后所有实例都开不了机；在任务管理器里结束 netsimd 进程再开机就好。用管理器或命令行开机的实例已经不用 netsimd 了。（[#65](https://github.com/ModAVD/ModAVD/issues/65)）
- Windows 注销、重启或关机时，开着的实例还是直接断电，不会先让安卓关机，和以前一样。关电脑前请先在 AUTO-MAS 或管理器里关掉实例。（[#60](https://github.com/ModAVD/ModAVD/issues/60)）
- 《明日方舟》偶尔在启动时报资源管理器初始化失败，随后把约 12.8 GB 的资源整包重新下载一遍；遇到过一次，排查没有发现模拟器丢数据，更像游戏自己把资源索引作废了，等它下完即可。（[#89](https://github.com/ModAVD/ModAVD/issues/89)）
- 用新版 Unity（6000.3）做的部分只有 arm64 版本的游戏，比如 World of Airports 3.7.3，商店里显示不兼容，侧载以后一启动就闪退。（[#131](https://github.com/ModAVD/ModAVD/issues/131)）

## English

ModAVD 0.38.2, build `mas-38`, built on Google AOSP Android Emulator 37.2.10. Installation, upgrades and feedback: see https://modavd.github.io/.

### New

- Optional Google Play Store: when fetching components, tick "同时补全 Google Play 商店服务" (also get the Google Play Store services), or import your own files, then add it to an instance from the instance's "更多操作" (more actions) menu. New instances come without it. ([#125](https://github.com/ModAVD/ModAVD/issues/125))

### Changes

- The manager and the command line in the package go from 0.4.1 to 0.5.0; see the [ModAVDManager releases](https://github.com/ModAVD/ModAVDManager/releases) for what changed in them. The emulator is still mas-38 and was not rebuilt.
- Fetching components and collecting problem info are now done in the manager, and the three `.bat` files at the package root are no longer shipped. ([#45](https://github.com/ModAVD/ModAVD/issues/45))

### How to update

- This version only repackages: the emulator is still mas-38 and was not rebuilt, the manager and the command line go to 0.5.0, and the execution bridge and the host input method are the same as in 0.38.1.
- `补全组件.bat`, `收集问题信息.bat` and `复制配置信息.bat` at the package root, and the three matching scripts under `tools`, are no longer shipped: fetch components and collect problem info in the manager, or run `tools\modavd.exe components fetch` and `tools\modavd.exe collect-info`. ([#45](https://github.com/ModAVD/ModAVD/issues/45))
  - Swapping the package with `modavd update` deletes these six old files; extracting over the old package by hand leaves them, and you can delete them yourself.
- If you want the Play Store: in the manager's "补全组件" (fetch components), tick "同时补全 Google Play 商店服务" (about 1.5 GB), or click "使用我自己的文件…" (use my own files) to import Google's official image zip; then choose "补全 Google Play 商店…" (add the Google Play Store) in the instance's "更多操作" menu. If sign-in says the device is not Play Protect certified, use "复制 GSF ID" (copy GSF ID) in the same menu and register it with Google. Games that check Play Integrity will most likely still fail it. Without the store there is nothing to do. ([#125](https://github.com/ModAVD/ModAVD/issues/125))
- Shut down all instances first (in AUTO-MAS or in the manager), then wait about half a minute before extracting. To update by hand, extract the whole new package over the old one; the `avd` folder is left alone. There is no need to add ModAVD to AUTO-MAS again.
- First install: the main package has no top-level folder, so use "Extract All…" or 7-Zip "Extract to <package name>\". Then double-click `ModAVD.exe`, click "补全组件" in the notice at the top to download adb and the system image, and create an instance. To use it with AUTO-MAS, add it there as well; see `说明.txt`.

### AUTO-MAS version

- `v5.7.0` or later is recommended, as for 0.38.1. This version has no new requirements for AUTO-MAS.

### Known issues

- The virtual disk does not shrink by itself after games or files are deleted, and the emulator's trim does not actually reclaim space yet; to save space, after shutdown use "compact disk" in the manager or `modavd disk <number> compact`. ([#2](https://github.com/ModAVD/ModAVD/issues/2))
- Onmyoji occasionally stops at "正在获取音频列表..." (fetching the audio list) during a cold start; close it and start it again. ([#36](https://github.com/ModAVD/ModAVD/issues/36))
- Emulators that AUTO-MAS starts itself (not through the manager or the command line) can still hit a hung netsimd with several instances, after which no instance can start; end the netsimd process in Task Manager and start again. Instances started from the manager or the command line no longer use netsimd. ([#65](https://github.com/ModAVD/ModAVD/issues/65))
- When Windows logs off, restarts or shuts down, running instances are still cut off without letting Android shut down first, as before. Shut the instances down in AUTO-MAS or the manager before turning off the computer. ([#60](https://github.com/ModAVD/ModAVD/issues/60))
- Arknights occasionally reports a resource manager initialization failure at startup and then downloads the whole ~12.8 GB of resources again. It has been seen once; the investigation found no sign of the emulator losing data, and it looks more like the game invalidating its own resource index. Let the download finish. ([#89](https://github.com/ModAVD/ModAVD/issues/89))
- Some arm64-only games built with the new Unity (6000.3), such as World of Airports 3.7.3, show as incompatible in the store, and crash right after launch when sideloaded. ([#131](https://github.com/ModAVD/ModAVD/issues/131))
