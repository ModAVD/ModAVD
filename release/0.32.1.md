ModAVD 0.32.1，构建号 `mas-32`，基于 Google AOSP Android Emulator 37.2.10 构建。安装、升级和反馈见仓库 README 与 `docs/`。

## 更新内容

### 说明

- 版本号改为 0.<构建号>.<重新打包次数>，这一版的模拟器就是 mas-32，只换了包格式：包里多了逐文件清单，主包去掉了外层文件夹（解压时请用「全部解压缩」）。

## 怎么更新

- 已经在用 mas-32 的，模拟器本身不用换：这一版的模拟器和 mas-32 相同，只是换成了新的版本号和包格式。
- 从更早的版本升级：在 AUTO-MAS 里关掉所有实例，用新包的 `sdk\emulator` 整个替换旧的。不用重新下载组件，也不用在 AUTO-MAS 里重新添加。
- 第一次装：主包里没有外层文件夹，请用右键「全部解压缩」或 7-Zip「解压到 <包名>\」。解压后双击「补全组件.bat」下载 adb 和系统镜像，再到 AUTO-MAS 里添加，详见 `说明.txt`。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 mas-32 相同。

## 已知问题

- 带窗口时底边上滑无法回桌面或打开最近任务，使用侧边栏的主页键。（[#1](https://github.com/ModAVD/ModAVD/issues/1)）
- 删除游戏或文件后虚拟磁盘不缩小；后续写入会复用空间。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- FAT32 / exFAT 上的首次建盘空间检查尚未实测，建议使用 NTFS。（[#3](https://github.com/ModAVD/ModAVD/issues/3)）
- 只支持 x86_64 系统镜像。（[#4](https://github.com/ModAVD/ModAVD/issues/4)）

- 模拟器是 mas-32 原样重新打包，没有重新编译；回归结果见 [v37.2.10-mas32 的发布说明](https://github.com/ModAVD/ModAVD/releases/tag/v37.2.10-mas32)。
