ModAVD 的第一个公开版本。基于 AOSP Android Emulator 37.2.10，构建号 `mas-30`（`sdk\emulator\source.properties` 里的 `Pkg.BuildId`）。

这一版换上了 ModAVD 自己的程序图标（`emulator.exe`、`emulator-check.exe` 和 x86_64 的 `qemu-system` 的程序图标与窗口图标）。图标是同人创作，不随本项目的任何许可证授权，见仓库 README 的「图标与美术」。

安装、升级、反馈的说明见仓库的 README 和 `docs/`。

## 主包里有什么

- `sdk\emulator\`：自编的 Android Emulator 37.2.10（mas-30）。
- `components\de.jrpie.android.launcher_57.apk`：轻量桌面 µLauncher 0.2.12（MIT），AUTO-MAS 第一次开机时装进安卓。
- `补全组件.bat`、`收集问题信息.bat` 和 `tools\` 里对应的脚本。
- `说明.txt`。
- `LICENSES\`：第三方组件声明 `NOTICE.txt` / `NOTICE.csv`，以及 Apache-2.0、GPL-2.0、LGPL-2.1、GPL-3.0、LGPL-3.0、MPL-2.0、µLauncher 许可证全文。`sdk\emulator\` 里的 `NOTICE.txt` / `NOTICE.csv` 是同一份修订版。

## 主包里没有什么

- **adb 和系统镜像**：属于 Google，受《Android 软件开发套件许可协议》约束，不能由我们分发。解压后运行「补全组件.bat」，同意许可协议后它会从 googledownloads.cn、腾讯云镜像、dl.google.com 依次尝试下载：
  - 平台工具（adb）37.0.1，约 8 MB；
  - 系统镜像 Android 14（API 34）Google APIs x86_64 r14，约 1.5 GB，解压后约 4.2 GB。
- 官方构建里挂机用不到的文件：`bin64\`（Cygwin 版 e2fsprogs）、`drivers\`（USB 直通驱动）、虚拟相机场景、宏示例、Pixel 10 皮肤、FlatBuffers 开发文件，以及 ARM 和 32 位 x86 的 `qemu-system`。

## 和内测包 mas-25 相比

- 首次建数据盘不再临时占满上限的空间；所在的盘是 NTFS / ReFS 时，首次建盘只要求 10 GB 可用（mas-25 对 64 GB 上限要 77 GB）。
- 安卓里的程序在 Vulkan 查询里带上电脑这边不认识的扩展结构时，不再直接退出（例如《明日方舟：终末地》）。
- 新增两个默认关闭的环境变量开关：`ANDROID_EMU_VK_HIDE_REBAR=1`、`ANDROID_EMU_VK_ASTC_BC3=1`（实验性）。
- Vulkan 绑定图像内存失败时，日志里多一行诊断。
- 侧边工具栏去掉了多任务键（换成轻量桌面以后，最近任务本来就打不开）。
- 程序图标和窗口图标换成了 ModAVD 自己的图标。
- 拿掉了上面「主包里没有什么」列的那些文件。
- adb 和系统镜像不再随包，改由「补全组件.bat」下载。

从内测包升级：关掉所有实例，用新包的 `sdk\emulator` 整个替换旧的，再把 `tools\`、两个 bat、`说明.txt`、`LICENSES\` 复制过去。不用重新下载组件，也不用在 AUTO-MAS 里重新添加。详见 `docs/upgrade.md`。

## AUTO-MAS 版本

推荐 `v5.7.0` 或更新：从这一版起，关机时先让安卓正常关机，游戏刚下载、写入的数据不会丢。各版本能配合魔改 AVD 使用的脚本：

| AUTO-MAS | 脚本 |
|---|---|
| v5.7.0-beta.2、beta.3 | M9A |
| v5.7.0-beta.4 | M9A、MAA |
| v5.7.0-beta.5 起 | MAA、全部 MFW 脚本（MaaFramework 项目，如 M9A） |

其他脚本暂不支持，选设备时会被拦下。

## 已知问题

- 带窗口时，从屏幕底边上滑回不了桌面，也打不开最近任务。请用侧边工具栏的 ○ 键回桌面。（[#1](https://github.com/ModAVD/ModAVD/issues/1)）
- 删掉游戏或文件以后，实例的磁盘文件不会变小（虚拟磁盘不支持回收空间）；新写入会复用腾出来的空间。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- 首次建盘只在 NTFS / ReFS 上放宽了空间检查；放在 FAT32 / exFAT 盘上仍按上限的 1.2 倍检查（这条没有实测）。建议放在 NTFS 盘上。（[#3](https://github.com/ModAVD/ModAVD/issues/3)）
- 只能运行 x86_64 的系统镜像。（[#4](https://github.com/ModAVD/ModAVD/issues/4)）

## 源码

主包里程序的完整对应源码，打在一个附件 `ModAVD-37.2.10-mas30-sources.zip` 里（只打包、不再压缩，里面的源码包本身已经压缩过）。解压后，`SOURCES.txt` 逐个说明这些文件是什么、取自哪里，`SHA256SUMS.txt` 是包内每个文件的 SHA-256。补丁和逐个补丁的许可证在仓库的 `patches/`。

- 24 个 AOSP 仓库在编译时的确切提交，每个是不带 `.git` 的 git archive，文件名是「项目路径-提交」。QEMU、gfxstream、Crashpad 三个是打了补丁的提交，QEMU 仓库里含构建脚本。
- 静态链接进程序的预编译库的源码：FFmpeg 4.4.2、libvpx v1.12.0（实际链接的版本）和 v1.11.0（FFmpeg 编译时配的版本）、libxml2 2.9.2、pixman 0.34.0（实际链接的版本，另附补丁）和 0.32.4（随库头文件的版本）。
- `lib\pc-bios` 里固件的源码：SeaBIOS（rel-1.11.1）和 iPXE。
- Qt 6.5.3 官方子模块源码，Qt 的构建脚本在 QEMU 仓库的 `android/build/python/aemu/prebuilts/qt.py`。
- `netsimd.exe`（Google 的预编译件，netsim `f113660d` 的 frontend-disabled 构建）静态链接的 GLib 的源码：GLib 2.82.2 上游包、`platform/build/bazel` `862d0ec3` 的 `glib 2.82.2.bcr.5.aemu` 模块、`platform/build/bazel` 整仓，以及 netsim `f113660d` 的源码，可以重建 netsimd 并重新链接 GLib。
- 两份仓库清单：`manifest-mas30.xml`（编译时各项目的提交）和 `manifest-aosp-base.xml`（全是 AOSP 公开提交，再打上补丁就得到前者）。仓库的 `manifests/` 里也各有一份。

## 校验

`SHA256SUMS.txt` 是主包和源码包这两个附件的 SHA-256（源码包里另有一份逐个文件的）。下载后可以用 PowerShell 核对：

```powershell
Get-FileHash .\ModAVD-37.2.10-mas30.zip -Algorithm SHA256
```

结果应与上表和 `SHA256SUMS.txt` 里的一致。
