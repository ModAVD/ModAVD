ModAVD 0.35.0，构建号 `mas-35`，基于 Google AOSP Android Emulator 37.2.10 构建。安装、升级和反馈见仓库 README 与 `docs/`。

## 更新内容

### 变更

- 每个实例静置时少占约 140 MB 内存：图形暂存缓冲改成按需增长，不再一开机就分配 128 MB（NVIDIA 显卡实测）。

### 说明

- 模拟器加了宿主输入法通道，为以后在窗口里直接用 Windows 输入法打中文等文字做准备；客体输入法还没有随包提供，这一版用起来和之前一样。

## 怎么更新

- 在 AUTO-MAS 里关掉所有实例，用新包的 `sdk\emulator` 整个替换旧的。不用重新下载组件，也不用在 AUTO-MAS 里重新添加。
- 第一次装：主包里没有外层文件夹，请用右键「全部解压缩」或 7-Zip「解压到 <包名>\」。解压后双击「补全组件.bat」下载 adb 和系统镜像，再到 AUTO-MAS 里添加，详见 `说明.txt`。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 mas-32 相同。

## 已知问题

- 带窗口时底边上滑无法回桌面或打开最近任务，使用侧边栏的主页键。（[#1](https://github.com/ModAVD/ModAVD/issues/1)）
- 删除游戏或文件后虚拟磁盘不缩小；后续写入会复用空间。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- FAT32 / exFAT 上的首次建盘空间检查尚未实测，建议使用 NTFS。（[#3](https://github.com/ModAVD/ModAVD/issues/3)）
- 只支持 x86_64 系统镜像。（[#4](https://github.com/ModAVD/ModAVD/issues/4)）

## 发布前回归

| 项目 | 结果 |
|---|---|
| 体检：开机、时钟源、MAA 与 MaaFW 截图、maatouch 点击、看门狗、关机 | 通过，冷启动 18.1 s。网络测速没跑（测试机没起测速服务） |
| 《重返未来：1999》运行 6 分钟 | 通过：游戏进程没有重启，无崩溃转储，模拟器日志无 Vulkan 校验报错 |
| 《崩坏：星穹铁道》运行 6 分钟 | 通过，同上 |
| 《明日方舟：终末地》冷启动 | 111 s 到标题。测的时候电脑内存紧张、在换页（可用内存最低 9.3 GB），比 mas-34 测试时的 67～83 s 慢；电脑空闲时和 mas-34 的对比还没测 |
| 宿主输入法通道（带窗口，配测试用的客体输入法）：中文、瑞典语字母和 emoji 上屏，组字，按键，删除，密码框，切到非文本控件 | 20 项全部通过 |

- 图形暂存缓冲：三个游戏运行的模拟器日志里都没有扩容或报错，16 MB 起步够用。
- 数据盘读写的代码和 mas-32 相同，这一版没有重跑强杀测试。
