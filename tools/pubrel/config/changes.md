## 怎么更新

- 这一版重编了模拟器（mas-37 到 mas-38），管理器和命令行升到 0.4.0；执行桥和宿主输入法和 0.37.1 一样，没有变。
- 先关掉所有实例（在 AUTO-MAS 或管理器里关机）再更新；关掉后稍等半分钟，模拟器的附属进程退出要十几秒，覆盖时提示文件被占用就再等一会儿重试。手动更新时用新包整个覆盖解压，`avd` 文件夹不会被动到。不用重新下载组件，也不用在 AUTO-MAS 里重新添加。
- 管理器 0.4.0 的自动换包（`modavd update`）要求根目录所在的盘支持按文件 ID 打开程序文件（NTFS 可以）；放在 exFAT / FAT32 上的根目录会拒绝自动换包、什么都不动，请手动下载整包覆盖。
- 第一次装：主包里没有外层文件夹，请用右键「全部解压缩」或 7-Zip「解压到 <包名>\」。解压后双击「补全组件.bat」下载 adb 和系统镜像，再双击 `ModAVD.exe` 新建实例；要接入 AUTO-MAS 的，再到 AUTO-MAS 里添加，详见 `说明.txt`。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 0.37.1 相同。这一版对 AUTO-MAS 没有新要求。

## 已知问题

- 删除游戏或文件后虚拟磁盘不会自动缩小，模拟器的 trim 还不会真正回收空间；要省空间，请在关机后用管理器的「整理磁盘」或命令行 `modavd disk <编号> compact`。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- 《阴阳师》冷启动偶尔停在「正在获取音频列表...」，关掉重开即可。（[#36](https://github.com/ModAVD/ModAVD/issues/36)）
- AUTO-MAS 自己起的模拟器（不经过管理器或命令行），多开时 netsimd 还可能卡住，之后所有实例都开不了机；在任务管理器里结束 netsimd 进程再开机就好。用管理器或命令行开机的实例已经不用 netsimd 了。（[#65](https://github.com/ModAVD/ModAVD/issues/65)）
- Windows 注销、重启或关机时，开着的实例还是直接断电，不会先让安卓关机，和以前一样。关电脑前请先在 AUTO-MAS 或管理器里关掉实例。（[#60](https://github.com/ModAVD/ModAVD/issues/60)）
- 《明日方舟》偶尔在启动时报资源管理器初始化失败，随后把约 12.8 GB 的资源整包重新下载一遍；遇到过一次，排查没有发现模拟器丢数据，更像游戏自己把资源索引作废了，等它下完即可。（[#89](https://github.com/ModAVD/ModAVD/issues/89)）

## 发布前回归

这一版改了测法：一台实例从开机到关机走一条流程，顺路测新功能、量帧率，流程没覆盖到的再单独补。游戏项都用各游戏自己的自动化脚本启动游戏、真跑任务，不在标题页挂机。模拟器用打进包的同一份 SDK。管理器：新建、按应用走代理、带窗口、整理数据盘、根目录搬走、换包和《阴阳师》《明日方舟》这几项用的是 0.4.0 发版前同一条主线编的预发版，其中整理的跳过和取消、关机后采集进程跟着退这两处改动另用含它们的版本补测；其余各项用 ModAVDManager v0.4.0 发布的那两个文件（和它 Release 上的 SHA256SUMS 逐字节相同）。帧率按「新版不比上一版明显差、没有卡顿掉帧」判；这次测试机开着睿频，上一版的基准是睿频关时测的，只记一笔。
