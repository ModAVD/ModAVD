## 怎么更新

- 这一版模拟器重新编过，带上了三处改动：
  - 调高分辨率后开机不再卡死退出（[#210](https://github.com/ModAVD/ModAVD/issues/210)）；
  - 带窗口的实例，标题栏加了最大化 / 还原按钮（[#185](https://github.com/ModAVD/ModAVD/issues/185)）；
  - 加了按键的控制台命令，截图库 v0.3.0 起的按键接口（返回、主页、多任务等）从这一版起能用。
- 包里的管理器和命令行升到 0.12.0，改动见[它的 Release](https://github.com/ModAVD/ModAVDManager/releases/tag/v0.12.0)；截图库和 MuMu 兼容外壳升到 [v0.3.1](https://github.com/ModAVD/ModAVDExtras/releases/tag/v0.3.1)。执行桥、宿主输入法和 0.40.3 一样。
- 在管理器「设置」里点「更新」。也可以把实例都关机、稍等半分钟，用新包整个覆盖解压。两种办法都不会动到 `avd` 文件夹，也不用在 AUTO-MAS 里重新添加。
- 从 0.40.2 及更早的版本点「更新」之前，一定先把实例都关机；0.40.3 起不用先关，管理器会列出要关的实例让你确认。
- 更新前请先关掉 MAA 这类载入了根目录里截图库或外壳的程序。没关的话，「更新」会提示是哪个文件被占着，什么都不动，关掉以后再点一次就行。
- 以前改过分辨率后开机会退出的：更新后直接开机就行。开机时如果还有程序拿着上一次的截图共享内存，管理器日志里会写出是哪个程序；这时截图工具可能要重开一次才能用快速截图。
- 关掉管理器窗口以后，管理器还留在托盘里。手动覆盖更新前，请在托盘图标的右键菜单里点「退出」。
- 第一次装：
  - 主包里没有外层文件夹，请用右键「全部解压缩」，或者 7-Zip 的「解压到 <包名>\」。
  - 解压后双击 `ModAVD.exe`，点上方提示里的「补全组件」，下载 adb 和系统镜像，再新建实例。
  - 要接入 AUTO-MAS 的，再到 AUTO-MAS 里添加。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 0.40.3 相同。这一版对 AUTO-MAS 没有新要求：管理器 0.12.0 的接口版本（`protocol`）还是 2，`--json` 没有删字段，只多了一个 `build_id`。
- 新建时语言没设成，`create` 不再报失败，也不用再 `create --resume`。
- AUTO-MAS 5.8.0 在组件不全时还会提示双击「补全组件.bat」，但 0.38.2 起包里没有这个文件了。请在管理器里点「补全组件」，或者运行 `tools\modavd.exe components fetch`，再回 AUTO-MAS 点「检查」。
## 已知问题

- 删除游戏或文件后，虚拟磁盘不会自动缩小：模拟器的 trim 还不会真正回收空间。要省空间，请在关机后用管理器的「整理磁盘」，或者命令行 `modavd disk <编号> compact`。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- 《阴阳师》冷启动偶尔停在「正在获取音频列表...」，关掉重开就好。（[#36](https://github.com/ModAVD/ModAVD/issues/36)）
- AUTO-MAS 自己起的模拟器（不经过管理器或命令行）多开时，netsimd 还可能卡住，之后所有实例都开不了机。在任务管理器里结束 netsimd 进程再开机就好。用管理器或命令行开机的实例已经不用 netsimd 了。（[#65](https://github.com/ModAVD/ModAVD/issues/65)）
- 《明日方舟》偶尔在启动时报资源管理器初始化失败，随后把约 12.8 GB 的资源整包重新下载一遍。遇到过两次，排查都没有发现模拟器丢数据，更像是游戏自己把资源索引作废了，等它下完就好。（[#89](https://github.com/ModAVD/ModAVD/issues/89)）

## 发布前回归

这一版模拟器重新编过，用候选包在两个测试根上各走一条流程（一条无头、一条带窗口），每项一遍：
- 模拟器就是要发的这一份；管理器和命令行是 ModAVDManager `release/0.41` 头上的 0.12.0，还没打 tag，两次编译逐字节相同；截图库和 MuMu 兼容外壳是 ModAVDExtras `release/0.41` 头上 CI 编出的 v0.3.1；宿主输入法、执行桥和 0.40.3 相同。
- 回归中途修了一处（开机后读时钟源，见表下），最终包只换了管理器的两个 exe 和清单；改到的那一项和包内容核对用最终包重测，其余各项是换之前测的。
