## 怎么更新

- 在 AUTO-MAS 里关掉所有实例再更新；关掉后稍等半分钟，模拟器的附属进程退出要十几秒，覆盖时提示文件被占用就再等一会儿重试。这一版包根多了 `ModAVD.exe`（管理器）、`tools\modavd.exe`（命令行）和 `tools\modavd-bridge.ps1`（arm64 执行桥的安装 / 卸载 / 检查），`components` 里多了宿主输入法 `modavd-ime.apk`：手动更新时用新包整个覆盖解压（`avd` 文件夹不会被动到），只换 `sdk\emulator` 就会少了它们。不用重新下载组件，也不用在 AUTO-MAS 里重新添加。
- 执行桥（玩只有 arm64 版本的《阴阳师》要用）不用自己装：升级后用管理器 `ModAVD.exe` 把每台实例开一次机，就会自动装上（第一次要多关机再开机一两次，约 1–2 分钟），之后照常用 AUTO-MAS 开机，桥一直在。只用 AUTO-MAS 开机、从不用管理器的实例，这一版还不会自动装。
- **要退回更早的版本，先在每一台实例上运行一次 `tools\modavd.exe bridge <编号> uninstall`**（在包根打开 PowerShell 运行），看到结果是「没装」再换包；卸过的实例以后开机不会再自动装。这一版起用管理器开过机的实例都装了桥。不先卸就退版，那台实例可能变成「系统属性指着一个已经不存在的库」，所有只有 arm64 版本的应用都跑不起来，而且界面上完全看不出来。
- 第一次装：主包里没有外层文件夹，请用右键「全部解压缩」或 7-Zip「解压到 <包名>\」。解压后双击「补全组件.bat」下载 adb 和系统镜像，再到 AUTO-MAS 里添加，详见 `说明.txt`。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 mas-32 相同。这一版对 AUTO-MAS 没有新要求：arm64 执行桥由包里的管理器 / 命令行装，装过桥的实例照常用 AUTO-MAS 开机。

## 已知问题

- 带窗口时底边上滑无法回桌面或打开最近任务，使用侧边栏的主页键。（[#1](https://github.com/ModAVD/ModAVD/issues/1)）
- 删除游戏或文件后虚拟磁盘不缩小；后续写入会复用空间。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- FAT32 / exFAT 上的首次建盘空间检查尚未实测，建议使用 NTFS。（[#3](https://github.com/ModAVD/ModAVD/issues/3)）
- 只支持 x86_64 系统镜像。（[#4](https://github.com/ModAVD/ModAVD/issues/4)）
