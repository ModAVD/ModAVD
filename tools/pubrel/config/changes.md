## 怎么更新

- 模拟器没有重编，和 0.40.2 是同一份。这一版换了两样：
  - 包里的管理器和命令行升到 0.11.0，改动见[它的 Release](https://github.com/ModAVD/ModAVDManager/releases/tag/v0.11.0)；
  - 截图库和 MuMu 兼容外壳升到 [v0.3.0](https://github.com/ModAVD/ModAVDExtras/releases/tag/v0.3.0)。
- 执行桥、宿主输入法和 0.40.2 一样。
- 在管理器「设置」里点「更新」就行。也可以先关掉所有实例（在 AUTO-MAS 或管理器里关机），稍等半分钟，再用新包整个覆盖解压。两种办法都不会动到 `avd` 文件夹，也不用在 AUTO-MAS 里重新添加。
- 从 0.40.2 点「更新」升上来的这一次，下载、关实例和换包用的还是旧版，所以「更新」的几处改动（下载时实例照常能用、关实例前再确认、换包时提示正在更新）要到下一次更新才看得到。
- 新建的实例语言和时区会跟着这台电脑；已有的实例不变，要改就在实例设置里选。改时区可能影响游戏每日刷新的时间。
- 更新前请先关掉 MAA 这类载入了根目录里截图库或外壳的程序。没关的话，「更新」会提示是哪个文件被占着，什么都不动，关掉以后再点一次就行。
- 关掉管理器窗口以后，管理器还留在托盘里。手动覆盖更新前，请在托盘图标的右键菜单里点「退出」。
- 第一次装：
  - 主包里没有外层文件夹，请用右键「全部解压缩」，或者 7-Zip 的「解压到 <包名>\」。
  - 解压后双击 `ModAVD.exe`，点上方提示里的「补全组件」，下载 adb 和系统镜像，再新建实例。
  - 要接入 AUTO-MAS 的，再到 AUTO-MAS 里添加。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 0.40.2 相同。这一版对 AUTO-MAS 没有新要求：管理器 0.11.0 的接口版本（`protocol`）还是 2，`--json` 没有删字段。
- 经 AUTO-MAS 新建的实例同样跟随这台电脑的语言和时区；`create`、`set` 多了可选的 `--language`、`--timezone`。
- AUTO-MAS 5.8.0 在组件不全时还会提示双击「补全组件.bat」，但 0.38.2 起包里没有这个文件了。请在管理器里点「补全组件」，或者运行 `tools\modavd.exe components fetch`，再回 AUTO-MAS 点「检查」。

## 已知问题

- 删除游戏或文件后，虚拟磁盘不会自动缩小：模拟器的 trim 还不会真正回收空间。要省空间，请在关机后用管理器的「整理磁盘」，或者命令行 `modavd disk <编号> compact`。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- 《阴阳师》冷启动偶尔停在「正在获取音频列表...」，关掉重开就好。（[#36](https://github.com/ModAVD/ModAVD/issues/36)）
- AUTO-MAS 自己起的模拟器（不经过管理器或命令行）多开时，netsimd 还可能卡住，之后所有实例都开不了机。在任务管理器里结束 netsimd 进程再开机就好。用管理器或命令行开机的实例已经不用 netsimd 了。（[#65](https://github.com/ModAVD/ModAVD/issues/65)）
- 《明日方舟》偶尔在启动时报资源管理器初始化失败，随后把约 12.8 GB 的资源整包重新下载一遍。遇到过两次，排查都没有发现模拟器丢数据，更像是游戏自己把资源索引作废了，等它下完就好。（[#89](https://github.com/ModAVD/ModAVD/issues/89)）

## 发布前回归

这一版模拟器和 0.40.1 是同一份，所以只测改了的地方，每项一遍。用的是这一版的候选包（升级和 5037 登记在 0.40.2 的候选上又测了一遍；新建、开机、截图、点击、关机中这几项是在前一轮候选上测的，那一轮的文件和这一版只差清单和 NOTICE 里的版本号）：
- 管理器和命令行是 ModAVDManager `release/0.40` 头上的 0.10.0，还没打 tag，两次编译逐字节相同。
- 截图库和 MuMu 兼容外壳是 ModAVDExtras `release/0.40` 头上 CI 编出的 v0.2.0，和它的校验表一致。
- 宿主输入法、执行桥和 0.40.1 相同。

- 截图库这一版起不再在本仓库钉版本和哈希（[#198](https://github.com/ModAVD/ModAVD/pull/198)）：打包时自动认出 ModAVDExtras `release/0.40` 头上的 v0.2.0，按它的校验表核对。
- 管理器的其他改动（托盘双击、卡片去掉运行时长、装桥时无头、更新时的占用检查和离线续装）由各自 PR 的单元测试和实机测试覆盖，这一轮没有重跑。要比 0.40.2 更新的已发布版本，才能在实机上走到新的更新代码，下一版发布前再测。
- 模拟器、执行桥、宿主输入法和 0.40.1 是同一份，游戏、GLES、执行桥、输入法没有重跑，见 0.40.0 的发布前回归。
- 关机都走正常关机（`modavd stop`，或 sync 后在安卓里关机），这一轮不做硬杀测试。
