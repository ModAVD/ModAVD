## 怎么更新

- 这一版只换了管理器和命令行（0.3.0 → 0.3.1），模拟器、执行桥、宿主输入法都和 0.37.0 一样。用 Mirror 酱（填了 CDK）更新时只下变了的文件；从 GitHub 下的还是整包。
- 先关掉所有实例（在 AUTO-MAS 或管理器里关机）再更新；关掉后稍等半分钟，模拟器的附属进程退出要十几秒，覆盖时提示文件被占用就再等一会儿重试。手动更新时用新包整个覆盖解压，`avd` 文件夹不会被动到。不用重新下载组件，也不用在 AUTO-MAS 里重新添加。
- 第一次装：主包里没有外层文件夹，请用右键「全部解压缩」或 7-Zip「解压到 <包名>\」。解压后双击「补全组件.bat」下载 adb 和系统镜像，再双击 `ModAVD.exe` 新建实例；要接入 AUTO-MAS 的，再到 AUTO-MAS 里添加，详见 `说明.txt`。

## AUTO-MAS 版本

- 推荐 `v5.7.0` 或更新，和 0.37.0 相同。这一版对 AUTO-MAS 没有新要求。

## 已知问题

- 删除游戏或文件后虚拟磁盘不缩小；后续写入会复用空间。（[#2](https://github.com/ModAVD/ModAVD/issues/2)）
- FAT32 / exFAT 上的首次建盘空间检查尚未实测，建议使用 NTFS。（[#3](https://github.com/ModAVD/ModAVD/issues/3)）
- 《阴阳师》冷启动偶尔停在「正在获取音频列表...」，关掉重开即可。（[#36](https://github.com/ModAVD/ModAVD/issues/36)）
- AUTO-MAS 自己起的模拟器（不经过管理器或命令行），多开时 netsimd 还可能卡住，之后所有实例都开不了机；在任务管理器里结束 netsimd 进程再开机就好。用管理器或命令行开机的实例已经不用 netsimd 了。（[#65](https://github.com/ModAVD/ModAVD/issues/65)）
- Windows 注销、重启或关机时，开着的实例还是直接断电，不会先让安卓关机，和以前一样。关电脑前请先在 AUTO-MAS 或管理器里关掉实例。（[#60](https://github.com/ModAVD/ModAVD/issues/60)）

## 发布前回归

这一版只换了管理器和命令行，模拟器、执行桥、宿主输入法都是 0.37.0 的同一份、没有重编，所以不重跑游戏、帧率和内存，只回归和管理器有关的几项。管理器的几项用 ModAVDManager v0.3.1 发布的那两个文件跑（和它 Release 上的 SHA256SUMS 逐字节相同），模拟器用打进包的同一份 SDK；后三项直接用打好的 0.37.1 包。

| 项目 | 判据 | 结果 |
|---|---|---|
| 默认装桥与分流：用 `modavd` 新建实例 | 新建后有开机标记；第一次开机自动装好桥；冷启动后桥在、GL 传输走 asg；`modavd bridge <编号> uninstall` 卸干净、`install` 又装上 | 通过：第一次开机连装桥共 36 秒 |
| 新建数据盘与扩容 | 新 16 GB 盘 inode 1048576；`set --data-gb 32` 后开机在线扩满；改小被拒 | 通过：inode 1048576，扩容后 /data 31.3 GB |
| 从 0.37.0 升级：新的管理器覆盖到 0.37.0 的根目录上 | 旧版建的实例照常开机、数据都在；旧盘改大后扩满；升级后照常开机自动装好执行桥 | 通过（「版本号是新的」不适用，见表下）：64 GB 盘改到 80 GB 后 /data 79.5 GB；执行桥自动装好 |
| 从 0.37.0 升级：照「怎么更新」把打好的 0.37.1 包整个覆盖上去 | 同上；包根清单的版本从 0.37.0 变成 0.37.1；输入法 APK 跟着包过来，客体装的是正式签名的那份并设为默认 | 通过（「版本号是新的」不适用，见表下）：64 GB 盘改到 80 GB 后 /data 79.5 GB；执行桥自动装好；客体里的输入法和包里的逐字节相同，默认是它 |
| 宿主输入法随包：用打好的包新建实例 | 第一次开机自动装上包里那份正式签名的输入法、启用、设为默认；通道 20 项；装着开发签名同一版本的实例，开机后换成正式签名、默认不变；再开机什么都不动 | 通过：第一次开机（含装桥）33 秒；通道 PASS 20，FAIL 0；换签名那次开机 1.3 秒 |
| 打好的包冒烟：用包建一个设了 `portBase` 的根目录，新建实例、开机、关机 | 管理器版本 0.3.1、protocol 2，实例端口在根目录的端口段里；开机不起 netsimd；`/sdcard` 能写；「复制配置信息」「收集问题信息」能用；前台开着应用时 `modavd stop` 在 28 秒内关完，再开机时关机前写的文件还在、上次关机原因是正常关机 | 通过：没起 netsimd；`stop` 7.8 秒；文件在，上次关机原因 shutdown |

- 两个升级项里「版本号是新的」这一条，回归工具按模拟器的构建号判；这一版构建号不变（都是 mas-37），这一条不适用。只换管理器那项，覆盖上去的两个 exe 和 v0.3.1 的 SHA256SUMS 相同；整包覆盖那项，新包包根清单的版本是 v0.37.1（上一版 v0.37.0），覆盖后包根的输入法 APK 是新包那份。
- 关机一律先 sync 再结束模拟器；这一轮不做硬杀测试。
