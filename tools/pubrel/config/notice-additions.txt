[ModAVD]
The arm64 execution bridge that tools\modavd-bridge.ps1 installs into an
instance: a native bridge entry shim (libmodavd_bridge.so), its companion
library (libmodavd_gate.so) and an init script (modavd_bridge.rc), written
by the ModAVD project. libmodavd_gate.so is statically linked with the
Android NDK's LLVM libc++ and libc++abi, which are licensed under the Apache
License 2.0 with LLVM Exceptions (https://llvm.org/LICENSE.txt); the
exception allows those portions to be redistributed in object form without
the notices the License would otherwise require. Source code:
https://github.com/ModAVD/ModAVD/tree/main/bridge; the source of this build
is ModAVD/bridge in modavd-src.tar.xz, in the sources ZIP of the same GitHub
Release.
